使用说明
1
在目标页面启动 ProtoPick

打开你想修改的网页，点击书签栏按钮（Chrome）或粘贴控制台代码（其他浏览器）。
适用于所有页面 — localhost · Vue · React · 生产环境

localhost:5173/dashboard
<header>
Dashboard · Settings · Profile
<main>
Welcome back, Alex
2
悬停高亮，点击选取元素

鼠标移到页面元素上，蓝色高亮框自动跟随。点击即选取该元素，支持多次点击选取多个元素。

localhost:5173/dashboard
<header>
Dashboard · Settings · Profile
<section class="hero">
Welcome back, Alex ← 已选取
div.card · React: HeroSection
3
为元素添加说明

点击元素后，弹出的批注框中输入你对这个元素的修改要求，比如「改成圆角」或「这里的颜色太深了」。

localhost:5173/dashboard
<section class="hero">
Welcome back, Alex
✏️ 把背景改成渐变色，文字居中
<nav class="sidebar">
Home · Analytics · Users
✏️ 加一个折叠功能
4
按 ⌘C 复制，粘贴给 AI

按 ⌘C 一键复制结构化提示词，包含 CSS 选择器、HTML 片段、框架信息。粘贴到任意 AI 助手即可使用。

Page: /dashboard 1. section.hero selector: main > section:nth-child(1) text: "Welcome back, Alex" html: <section class="hero">...</section> component: HeroSection (React) instruction: 把背景改成渐变色，文字居中
AI
Claude Code / Cursor / Codex
AI 收到完整的元素上下文，精确理解你要改什么、改哪里，直接输出对应的代码修改。
