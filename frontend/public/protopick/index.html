使用说明
1
在目标页面启动 ProtoPick

打开你想修改的网页，点击书签栏按钮（Chrome）或粘贴控制台代码（其他浏览器）。
适用于所有页面 — localhost · Vue · React · 生产环境
面板标题栏可拖拽移动，按 ⇧P 暂停/恢复选取，点击历史按钮查看复制记录。

localhost:5173/dashboard
<header>
Dashboard · Settings · Profile
<main>
Welcome back, Alex
2
悬停高亮，点击选取元素

鼠标移到页面元素上，橙色高亮框自动跟随。点击即选取该元素，右侧出现操作按钮。
面板中显示 DOM 路径面包屑，点击路径段可快速跳转到父级元素。

localhost:5173/dashboard
<header>
Dashboard · Settings · Profile
<section class="hero">
Welcome back, Alex
main › section.hero
3
方向键快速导航 DOM

选取元素后，使用 ↑ ↓ ← → 方向键在 DOM 树中快速移动选区。
↑ 跳到父元素 · ↓ 进入子元素 · ← → 切换兄弟元素。到达边界时选框闪红提示。

localhost:5173/dashboard
<header>
Dashboard · Settings · Profile
<main>
section.hero  ← 当前选中 section.features  → 按右箭头
↑ 父级   ↓ 子级   ← → 兄弟
4
批注并加入收集区

点击 ✎ 按钮为元素添加修改说明，比如「改成圆角」或「颜色太深」。然后点击 ＋ 按钮或按 ⌘Enter 将元素加入收集区。
可重复选取多个元素，逐一添加批注后加入收集区，统一生成提示词。

localhost:5173/dashboard
<section class="hero">
Welcome back, Alex
✎ 把背景改成渐变色，文字居中
<nav class="sidebar">
Home · Analytics · Users
✎ 加一个折叠功能
5
自动捕获控制台报错

ProtoPick 启动后自动监听页面的 console.error、运行时异常和未处理的 Promise 拒绝。
捕获到错误时，面板标题栏出现红色徽章，顶部弹出提示。点击徽章可展开错误详情，报错信息也会一并复制到提示词中。

localhost:5173/dashboard
选取中 3
TypeError: Cannot read properties of undefined
at HeroSection.vue:42:15
Unhandled: NetworkError: Failed to fetch
at api.js:18:11
Warning: Each child in a list should have a unique key
6
按 ⌘C 复制，粘贴给 AI

按 ⌘C 或点击「复制提示词」按钮，一键复制所有已收集元素和捕获报错的结构化提示词，包含 CSS 选择器、源文件位置、框架组件信息、HTML 片段、修改说明和错误堆栈。
每个元素的 HTML 片段最多保留 2000 字符，如需完整内容请缩小选取范围。

AI
Claude Code / Cursor / Codex
AI 收到所有已收集元素的完整上下文和修改说明，精确理解每个元素要改什么，直接输出对应的代码修改。
7
复制历史，随时回溯

每次复制 Prompt 后自动保存到历史记录（按域名隔离，保留最近 10 条）。点击面板标题栏的历史按钮即可查看。
支持快速复制、查看详情和删除，无需重新选取元素。
